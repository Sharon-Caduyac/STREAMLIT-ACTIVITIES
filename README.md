In Activity 4, I developed a Streamlit application that connects to a public COVID-19 API using the requests library. The app fetches and parses real-time JSON data about COVID-19 statistics for multiple countries. The data is displayed using Streamlit widgets, including a multiselect dropdown that allows users to choose which countries to view. The results are visualized using five different chart types: a bar chart for total cases, a line chart for deaths and recoveries, an area chart for active and critical cases, a pie chart for today’s statistics, and an Altair scatter plot for tests versus population. The app handles missing data gracefully and provides an interactive and informative dashboard for users.
