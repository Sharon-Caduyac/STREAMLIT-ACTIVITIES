This Streamlit app uses a sidebar (st.sidebar) to provide a dropdown menu for navigating between different sections related to Data Warehousing and Enterprise Data Management. Each section is structured using layout components like st.columns for side-by-side display of metrics or text, and st.expander to hide or reveal detailed information, keeping the interface clean. The Home section introduces EDM concepts, while pages like ETL Workflow, Data Quality Dashboard, and Metadata Overview provide visual explanations and tables. Images in sections like ETL Workflow and Data Lineage Heatmap enhance understanding through visual representation. Overall, the layout ensures the dashboard is interactive, organized, and informative for exploring key enterprise data topics.
